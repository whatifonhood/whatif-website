title: 工具

---

本站是一组建立在公开数据之上的小工具。它们都不需要账户、钱包连接或签名。在展示实时数据所允许的范围内，它们在禁用 JavaScript 的情况下也都能用。

## 数据页

[数据页](/zh/stats/)。价格、市值、流动性、成交量和持有者，这些数字先由构建时的一份快照渲染出来，等 API 给出应答再换成实时的。如果某次调用失败，页面会继续显示那份快照并附上它的采集日期，而不是一个加载图标或一片空白。

页面上还有价格走势图、买卖压力、每一笔交易都带链接的销毁记录、持有者表格、任何人都能自己跑一遍的核查，以及[自己去验证](/zh/docs/verify-it-yourself/)里的那些命令。

## 钱包查询

[查询工具](/zh/holdings/)接受任意地址，从链上读取它的 $IF 余额。不用连接，不用签名，没有任何东西要你批准 —— 公开读取不需要权限。

你可以查任何地址，包括不属于你的地址。这是公开账本的性质，不是我们加上去的功能。

## 问一个更好的问题

[问题生成器](/zh/ask/)。几千种 _what if_ 的变体，外加每天一个对所有人都相同的共享问题。

它是这里最不正经的工具，也是最接近整个项目要点的那一个。

## 找到你的币

[抽币](/zh/pfp/)。150 张作品，分四种稀有度。免费，不用钱包，不铸造任何东西，链上没有任何东西 —— 它就是一张图，抽一次不花钱，因为根本没有可以收费的东西。

你抽到的东西存在你自己的浏览器里，从不发送到任何地方。用一个代码可以把收藏搬到另一台设备上。

## 迷因库

[迷因](/zh/memes/)，完整分辨率，无水印，不需要署名。拿去用。

## 刻意不做的事

- **不做钱包连接**，任何地方都不做，理由见[钱包与托管](/zh/docs/wallets-and-custody/)。
- **不做价格预测**，没有目标价，没有“下一个百倍”。
- **不用第三方追踪器。** 分析是第一方的，不带 cookie；社区墙用构建时抓取的文本来渲染帖子，而不是嵌入任何会盯着你阅读的东西。
- **不作出我们无法举证的主张。** 参见[我们不声称的东西](/zh/docs/what-we-do-not-claim/)。
